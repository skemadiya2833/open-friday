# Attention residue

**Attribution:** Sophie Leroy — attention residue research (paraphrased)  
**Evidence:** some

- Switching tasks leaves part of your mind on the previous task — plan for switch cost.
- Finish a micro-closure note before jumping (next step, parking lot).
- Batch similar work to reduce context shifts.
- Avoid stacking back-to-back different deep topics without buffer.
- Single-task windows beat rapid multitasking for quality work.
- Notifications are switch triggers — treat them as expensive by default.
