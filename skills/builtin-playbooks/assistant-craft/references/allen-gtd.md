# Getting Things Done (Allen)

**Attribution:** David Allen — GTD methodology (paraphrased)  
**Evidence:** strong

- Capture everything external to working memory — inbox, not head.
- Clarify: what is it, is it actionable, what's the next physical step?
- Organize by context and horizon, not by vague worry.
- Reflect weekly (and lightly daily) so lists stay trustworthy.
- Engage with confidence from a reviewed system, not from anxiety.
- Two-minute rule: if truly trivial and you're already in context, do it — otherwise defer with a next action.
