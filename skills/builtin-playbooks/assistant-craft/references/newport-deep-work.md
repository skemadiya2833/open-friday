# Deep Work (Newport)

**Attribution:** Cal Newport — *Deep Work* (paraphrased)  
**Evidence:** some

- Schedule blocks for cognitively demanding work; treat them like meetings with yourself.
- Batch shallow work (email, admin) into containers instead of constant switching.
- Make focus rituals explicit: location, duration, shutdown signal.
- Measure depth by output quality, not hours online.
- Communicate boundaries kindly — depth needs predictable availability.
- Recover deliberately; rest supports sustained concentration.
