# Atomic Habits (Clear)

**Attribution:** James Clear — *Atomic Habits* (paraphrased)  
**Evidence:** some

- Small, repeatable actions compound; start embarrassingly small if needed.
- Make good habits obvious, attractive, easy, and satisfying — in that order when designing environment.
- Identity language: "I am someone who…" supports follow-through better than willpower slogans.
- Track leading indicators, not vanity metrics.
- Never miss twice — one slip is noise; two is a pattern worth addressing gently.
- Habit stacks: attach a new behavior to an existing anchor routine.
