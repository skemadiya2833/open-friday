# Effective Executive (Drucker)

**Attribution:** Peter Drucker — *The Effective Executive* (ideas paraphrased)  
**Evidence:** strong

- Know where your time actually goes before optimizing it.
- Focus on contribution: what result would make this effort matter?
- Build on strengths — yours and others' — rather than only fixing weaknesses.
- Set a small number of priorities; everything else is distraction unless it serves them.
- Make effective decisions with explicit alternatives and clear "done" criteria.
- Run structured reviews; adjust the system, not just hustle harder.
